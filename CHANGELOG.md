# Changelog

All notable changes to the n8n-nodes-agentsgt package will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.1] - 2025-07-26

### Added
- Comprehensive documentation including:
  - Detailed README.md
  - README_USAGE.md with advanced usage examples
  - QUICK_REFERENCE.md for quick lookup
  - CHANGELOG.md to track version history

### Fixed
- Minor formatting issues in documentation

## [1.0.0] - 2025-07-01

### Added
- Initial release of the AgentsGT node
- Support for Agent resource with Get Many operation
- Support for Chat resource with Send Message operation
- Support for Balance resource with Check Balance operation
- Three chat types: Basic, Advanced, and CopilotKit
- Comprehensive error handling
- API credential management

### Security
- Secure handling of API keys
- Authentication via Bearer token

## Future Plans

Planned features for upcoming releases:

- Support for agent creation and management
- Webhook integration for real-time notifications
- File upload and processing capabilities
- Advanced conversation management
- Integration with AgentsGT knowledge bases
- Support for team collaboration features
